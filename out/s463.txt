The Qwen-2.5-72B sweep returns $\tau^{*} = 2.68$ (bootstrap CI $[1.92, 7.23]$). The canonical family-a × LLMLingua-2 synthetic reference from `results/h1_h2_v2/verdicts.json` is $\tau^{*}_\text{canonical} = 2.5$ (the selected logistic fit; see §4.3 Table 4.2); the Qwen-72B point estimate is **$\sim 7\%$ above** this reference and the bootstrap CI comfortably contains it. (A separate auxiliary fit on the original `h1_h2_final` curve produces $\tau^{*}_\text{aux} = 2.6997$, against which Qwen-72B is $0.8\%$ off; this is the number quoted in the project's earlier audit-trail JSON but is not the canonical fit. The "$\sim 7\%$ off canonical, CI contains canonical" framing is the one this thesis stands by.) This is the most direct evidence for Corollary 1's *within-family parameter scaling* claim: same model family (Qwen-2.5), same compressor (LLMLingua-2), a **48× change in parameter count** from local 1.5B Qwen-2.5 to frontier 72B Qwen-2.5, and the cliff position falls in the same 2--3$\times$ ratio band with the bootstrap CI containing the canonical reference. (The 48× scope is the local-to-frontier Qwen-2.5 jump on the family-a × LLMLingua-2 cell; cross-family or cross-compressor scaling of the 72B planner is not part of the sweep.) The baseline coordination $p_0(\text{Qwen-72B}) = 1.00$ is at the ceiling, which places the model squarely inside the calibrated regime: there is no floor effect to argue around.

### 4.6.3 DeepSeek V4 Pro: in-regime, CI contains the prediction

The DeepSeek V4 Pro sweep returns a $\tau^{*}$ point estimate of 2.15 with a bootstrap CI of $[1.76, 7.14]$ — width $5.4$ ratio units, wider than the interesting region of the cliff sweep. The CI is wide because the sweep was run with the same small per-cell sample as Qwen-72B (10 workloads × 3 seeds per ratio) and DeepSeek's coordination curve happens to have more bootstrap-resample variance at the cliff position; the point estimate is below the canonical synthetic reference $\tau^{*}_\text{canonical} = 2.5$ but the CI contains it. The right framing is therefore: DeepSeek is consistent with Corollary 1 *with limited resolving power* — the CI is wide enough that it would also contain many other cliff positions, so the result is not a point-estimate match but a within-CI validation. The aggressive reading (DeepSeek cliffs slightly earlier than Qwen-72B because its critical-token-recall profile under LLMLingua-2 differs from Qwen's) is plausible and could be distinguished by sweeping DeepSeek with more seeds; the thesis takes the conservative reading.
